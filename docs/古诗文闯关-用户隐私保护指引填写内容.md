# 用户隐私保护指引 · 平台侧填写内容

> 用途：WorkBuddy 应用卡「小程序设置 → 用户隐私保护指引」弹窗填写

## 填写原则

平台侧的「用户隐私保护指引」是**结构化声明**，与代码里的隐私政策页是两回事。两者内容必须一致。按实际收集情况，**只勾选邮箱相关项**，其他一概不勾，避免审核判定"声明与实际不符"。

---

## 一、收集的信息（逐项填写）

### 1. 电子邮箱

| 字段 | 填写内容 |
|---|---|
| 信息类型 | 电子邮箱地址 |
| 收集目的 | 用于用户主动选择"保存成绩到云端"时创建账号、发送验证码，以及跨设备同步通关进度 |
| 使用方式 | 仅在用户主动填写并提交后收集；用于账号识别与验证码通信；不用于营销推送 |
| 是否必需 | 非必需。不登录也能完整游玩 |
| 保存期限 | 用户主动删除账号前持续保存；用户申请删除后同步删除 |
| 共享给第三方 | 否（仅通过腾讯云服务传输，用于账号会话，不构成对外共享） |

### 2. 设备存储信息（本地进度）

| 字段 | 填写内容 |
|---|---|
| 信息类型 | 设备本地存储（非个人信息采集） |
| 收集目的 | 保存通关星数、积分、收藏、错题与个性化设置，用于断点续玩 |
| 使用方式 | 仅存储在本机，不上传、不用于画像 |
| 是否必需 | 是（用于基础游玩体验） |
| 保存期限 | 用户清除小程序数据前持续保存 |

## 五、备案与 UGC 两项的处理

### 小程序备案
你已提交备案。**备案审核通过前无法提交正式版审核**——这是微信的硬性前置。备案通过后才能点提审。

### UGC 信息安全声明
本小程序**没有用户生成内容**：没有评论、发帖、昵称、头像上传、社交互动。诗库内容是平台预置的，用户只产生本地学习进度。

如平台要求填写该声明，选择"不涉及用户生成内容"或类似选项即可；若必须填写，文本如下：

> 本小程序不提供用户生成内容（UGC）功能。用户无法发布、评论、上传任何文字、图片或音视频内容。小程序内所有诗文、配图与题目均由开发者预置，用户仅产生本地学习进度数据，不涉及社交、社区、论坛、笔记、问答等场景。
