## 二、5 种古文题型（为什么必须新造）

诗词题型依赖 `lines`（诗句数组），古文没有这个字段，直接套用会崩。古文数据是 `cards`
（每张含 `text 原文 / trans 译文 / words 实词 / pause 停顿`），所以 5 种题型全部基于 cards 出题，
且都是四选一，**复用现有答题页交互，没有新增复杂操作**：

| 题型 | 玩法 | 干扰项来源 |
|---|---|---|
| `trans` 文句翻译 | 给文言原句 → 选正确译文 | 其他卡片译文（长度相近优先） |
| `read` 文意理解 | 给白话译文 → 选对应文言原句 | 其他卡片原句 |
| `word` 实词释义 | 句中「某词」是什么意思 | 其他卡片实词释义 |
| `wf_fill` 文言填空 | 挖去一个实词 → 补全 | 同字数实词 |
| `pause` 诵读断句 | 无标点句 → 选正确停顿 | 同句不同切分 |

档位解锁：tier7 三型（断句/实词/填空）→ tier8 加翻译 → tier9 加文意 → tier10 五型全开。
