## 2. 服务器域名白名单（真机必须）

路径：微信公众平台 → 开发 → 开发管理 → 开发设置 → **服务器域名** → `downloadFile 合法域名`（音乐）与 `request 合法域名`（稳妥起见两处都加）。

自托管方案下，只需加入**你自己的图床/CDN 域名**（配图和音乐同一个域名即可）：

```
https://你的域名      # 例如 https://cdn.example.com，对象存储默认域也可以
```

要点：

- 域名必须是 **https**、已备案（大陆主体）、且**不带路径与端口**。每月可修改次数有限，一次加齐。
- 配图走 `request`（`question-factory` 里图片是 image 组件 src，通常走 downloadFile；两处都加最稳）；音乐走 `downloadFile`（`wx.createInnerAudioContext`）。
- 音乐 URL 加载失败会自动降级到包内兜底，不崩，但真机听不到完整曲子——所以白名单要配对。
- **不再需要** Wikimedia 任何域名：配图已改为自托管摄影照，云端 payload 里的 `real` 全部指向你自己的域名（旧国画直链已清空）。

## 3. 云端写入：配图整表替换为 123 条（自托管摄影照）

数据源（**用第 2.5 节脚本生成，不要用旧文件**）：

```
illustration-samples/deploy-out/cloud-illustrations.json   # 123 条，real 已指向你的自托管域名
```

- 结构：`{ "p01": {path, motif, caption, real, credit, license}, ... }`，共 123 条。
  - 其中 **80 首** `real` = `https://你的域名/tangshi/images/pXX.jpg`（逐首诗意匹配的真实摄影照，CC0/公有领域）。
  - 其余 **43 首** `real` 置空（无合适摄影照，回退包内生成图，不再是旧国画）。
- 写入目标：云数据库 `game_catalog` 表，`kind = 'illustrations'` 那一行的 `payload` 字段。
- **操作方式**：用 WorkBuddy 云服务的数据库写入能力（或你惯用的 DB 工具），把该 JSON 作为 `payload` **整表替换**。**写入由你本人操作**。

> 为什么整表替换而不是追加：云端现存 54 条旧配图**没有 real 字段**（是包内生成图的 path/caption）。若只追加增量，旧 54 首仍无真实图。整表替换能一次让 80 首有自托管摄影照、其余 43 首干净回退。

写入后核验（读回）：

```
SELECT kind, jsonb_object_length(payload) FROM game_catalog WHERE kind='illustrations';
-- 期望：123 条；抽 p01 的 real 应以 https://你的域名/tangshi/images/ 开头；抽 p03 的 real 应为空
```

注意事项：

- 必须先按第 2.5 节跑脚本填**你的真实域名**，再写库；用示例域名 `cdn.example.com` 生成的 payload 写进去会全是死链。
- `game_catalog` 是公开读表（anon/authenticated 均可 SELECT），写入不要破坏 RLS 策略。
- 预览版与已发布版**共用同一云服务**：写入的内容预览器立刻可见，写入后注意别用测试数据污染正式内容。
- 想替换某首诗的图：把新图命名成对应 `pXX.jpg` 覆盖上传即可（URL 不变，无需改库）；要换 URL 规则才需改脚本参数重跑。

## 6. 常见问题

- **真机远程图/音乐加载失败** → 99% 是域名白名单没配或配错（必须是 https、无路径无端口、`downloadFile`+`request` 都加）。先看微信开发者工具的 Network/Console 报错域名。
- **本地预览正常、真机不行** → 正常，预览器不走 wx 原生能力，一切以真机为准。
- **音乐只有短循环** → `remoteUrl` 还是空的，或远程 MP3 加载失败降级了；检查第 4.2 步。
- **配图还是旧的 54 条/无真实图** → 第 3 步云端整表替换没做或没成功，读回核验。
- **改了配置没生效** → 代码改动需重新构建/发布；预览器会立刻用新配置，但体验版/正式版要重发。
- **云服务资源点用尽** → 不会扣钱，自动暂停，数据保留 30 天；升级套餐或等下月刷新。
- **真机测试产生的登录用户/进度** → 与已发布版共用云服务，正式发布前留意清理测试进度（公开目录 `game_catalog` 是正式内容，不用清）。
